# Пакети для подорожей

Сторінка `travel-plans.html` автоматично отримує актуальні пакети з eSIM Access. Для кожного пакета сервер сам перевіряє код і повторно розраховує ціну перед створенням Stripe Checkout. Створювати окремий Stripe Price ID для кожного пакета не потрібно.

Стандартне ціноутворення:

- націнка 35%;
- щонайменше 1 USD понад закупівельну ціну;
- мінімальна ціна 2.99 USD;
- кінцева ціна округлюється до `.99`.

За потреби у Render можна додати:

- `PACKAGE_MARKUP_PERCENT=35`
- `PACKAGE_FIXED_MARKUP_USD=1`
- `PACKAGE_MIN_PRICE_USD=2.99`

Не встановлюй націнку нижче витрат Stripe та податків. Після деплою відкрий каталог під тестовим акаунтом, звір кілька цін із кабінетом eSIM Access і зроби одну оплату в Stripe Test Mode перед увімкненням Live Mode.

Поки акаунт підтримує одну активну eSIM, система не дозволяє випадково замінити її новим туристичним пакетом. Для такого користувача показується прохання звернутися в підтримку.
