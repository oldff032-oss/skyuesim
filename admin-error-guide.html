📘 Довідник помилок

Знайди код із «Діагностики» та виконай безпечну дію.

Як читати журнал

Request ID / Purchase ID
Request ID зв’язує застосунок із backend. Purchase ID зв’язує Stripe Checkout, webhook і видачу eSIM.
Дія: встав ID у пошук «Діагностики» та знайди перший крок failed або blocked.
started → success / failed / blocked
started — почалось; success — завершено; failed — збій; blocked — небезпечну дію навмисно зупинено.
Дія: не повторюй оплату, якщо вже є checkout_completed.

Каталог пакетів

CATALOG_PROVIDER_ERROR
Не отримано каталог eSIM Access.
Виправлення: перевір ключ, баланс, API і Render Logs за Request ID.
PACKAGE_CODE_INVALID
Код пакета неправильний або запит змінено.
Виправлення: онови каталог; повторення перевір як підозрілу активність.
PACKAGE_NOT_AVAILABLE
Пакет змінився до оплати; гроші ще не списані.
Виправлення: онови каталог і вибери інший пакет.
ACTIVE_ESIM_EXISTS
Покупку заблоковано, щоб не замінити активну eSIM.
Виправлення: додатковий пакет оформлюй через підтримку.

Stripe та оплати

STRIPE_CHECKOUT_ERROR
Checkout не створився; кошти не списані.
Виправлення: перевір Stripe mode, ключ, валюту й Request ID.
Webhook signature verification failed
Webhook secret не відповідає endpoint.
Виправлення: скопіюй signing secret активного endpoint у Render і зроби restart.
checkout_completed
Stripe підтвердив оплату. Це нормальна подія.
Дія: далі очікуй provision_started і provision_completed. Якщо provision_failed — не списуй повторно.
invoice.payment_failed
Банк або Stripe не провів автосписання.
Виправлення: користувач оновлює спосіб оплати; пакет не видавай до paid.
receiptEmailError
Покупку збережено, але email із чеком не доставлено.
Виправлення: перевір Resend і домен; чек залишається в історії оплат.

eSIM Access

ESIM_PROVISION_FAILED / payment_ok_esim_failed
Оплату підтверджено, але eSIM не видана.
Виправлення: знайди Purchase ID, усунь причину й зроби retry або refund. Не проси платити повторно.
balance is insufficient
Недостатній баланс eSIM Access; HTTP 200 не означає успіх.
Виправлення: поповни баланс і лише потім повтори видачу оплаченої покупки.
data plan code doesn't exist
Код пакета видалено або він недоступний.
Виправлення: онови каталог; не вводь packageCode вручну.
top up ... incompatible
Top-up несумісний із конкретним ICCID.
Виправлення: запитай TOPUP-пакети саме для цього ICCID.
PROFILE_NOT_READY / 200010
Профіль ще створюється у SM-DP+.
Виправлення: дочекайся контрольованого polling; не створюй нову оплату.
renewal_failed
Щомісячну оплату отримано, але пакет не поновлено.
Виправлення: усунь причину й повтори конкретний invoice, не всю оплату.

HTTP, мережа та застосунок

HTTP_400
Неправильні або неповні дані.
Виправлення: перевір поля, packageCode і message.
HTTP_401 / HTTP_403
Недійсна сесія або заборонена дія.
Виправлення: повторний вхід; перевір роль і власника даних.
HTTP_404 / HTTP_409
Об’єкт не знайдено або стан конфліктує з дією.
Виправлення: онови дані та не дублюй операцію.
HTTP_429
Забагато запитів.
Виправлення: зачекай Retry-After.
HTTP_500 / HTTP_502 / HTTP_503
Помилка backend, провайдера або конфігурації.
Виправлення: звір Request ID, provider і Render Logs; не роби сліпий retry платежу.
network_error / Failed to fetch
Немає зв’язку з API: інтернет, CORS, API_URL або Render.
Виправлення: перевір HTTPS, URL, ALLOWED_ORIGINS і стан Render.
javascript_error / promise_rejection
Збій інтерфейсу або фонової операції.
Виправлення: перевір page, file/line у context і PWA-кеш після deploy.

Email, push і 2FA

Resend 401 / 403
Неправильний API key або непідтверджений домен.
Виправлення: онови RESEND_API_KEY і RESEND_FROM_EMAIL.
push delivered: 0 / VAPID
Немає активного пристрою або ключі push неправильні.
Виправлення: перевір VAPID-пару, дозвіл браузера й перепідключи пристрій.
TWO_FACTOR_INVALID / TWO_FACTOR_EXPIRED
Код неправильний, використаний або старший 10 хвилин.
Виправлення: почни вхід заново та використай найновіший лист.
